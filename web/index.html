n64forthos

A Forth operating system for the Nintendo 64, running here in an emulator written for this repository — which is why the page can hand it a real mouse and keyboard: they arrive as an N64 Mouse and a Randnet Keyboard on joybus channels 2 and 3, the same way a BlueRetro adapter presents them to the real console.

Click the picture to give it the mouse (Esc takes it back). Type at the Forth prompt with your own keyboard. Arrow keys, Z, X and Enter are the controller if you would rather use one.
