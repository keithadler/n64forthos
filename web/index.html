n64forthos

A Forth operating system for the Nintendo 64, in an emulator written for this repository — so the page can hand it a real mouse and keyboard, as an N64 Mouse and a Randnet Keyboard on joybus channels 2 and 3, exactly as a BlueRetro adapter presents them to the console. Click the picture for the mouse (Esc takes it back). Type, or paste a program straight in. Your files go on the Controller Pak, kept in this browser.
